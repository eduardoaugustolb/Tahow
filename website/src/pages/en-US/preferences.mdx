## Configuration file

The canonical file is `~/.config/tahow-shell/settings.json`, respecting XDG_CONFIG_HOME. Until it exists, `~/.config/tahoe-shell/settings.json` remains a readable fallback. The first write uses the canonical path.

Startup reads the canonical file before considering one-time legacy migration. Edits are saved atomically before returning, so restarting the shell does not discard pending changes. An unreadable or malformed existing file is preserved; persistence errors are logged.

## General and overrides

Root fields are General. Component adjustments live under `overrides.island`, `overrides.palette` and `overrides.lockscreen`.

```json
{
  "appearance": "dark",
  "accentSource": "wallpaper",
  "motion": "balanced",
  "overrides": {
    "island": { "glassOpacity": 0.55 },
    "palette": { "motion": "bouncy" },
    "lockscreen": { "use24h": true }
  }
}
```

## Restore general defaults

Use General clears component overrides. On the Glass page it only removes glass overrides, preserving unrelated preferences.

## Language and motion

Choose `en-US`, `pt-BR` or automatic selection. Hosted automatic selection uses the Ryoku default. Motion profiles are gentle, balanced, bouncy and reduced.

The preferences window follows the general appearance and desktop accent.
