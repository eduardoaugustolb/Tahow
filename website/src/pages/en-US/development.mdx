## Architecture

| Layer | Responsibility |
| --- | --- |
| Config | Sole preferences writer and scope resolution |
| Theme | Colors, fonts, material and motion |
| Runtime | Shared services and surfaces |
| Host and adapters | Desktop-specific integration |

The `shell/shell.qml` entry remains independently runnable. Ryoku imports belong in adapters.

## Validation

```sh
bun run check
bun test
bun tools/build-shaders.ts
bun tools/sync-i18n.ts
```

Include shader sources and generated .qsb artifacts together. Shell strings must exist in en-US and pt-BR.

## This documentation

Pages live in `website/src/pages/{locale}/*.mdx`. The layout is `website/src/layouts/Docs.astro`. CSS tokens reproduce Theme.qml and SettingsWindow.qml.

```sh
bun run docs:install
bun run docs:dev
bun run docs:build
```

The GitHub Pages workflow builds the static site with Bun. The production domain is tahow.eduardoaugusto.work.

## Animated brand banner

The approved banner combines the existing generated glass-orbit background, approved logo and bundled Sacramento font. It uses the reload screen's flow and text-refraction shaders, plus local logo deformation. Visible artwork bounds align the logo and signature as one centered composition.

```sh
bun tools/build-shaders.ts
bun tools/animate-banner.ts
```

The renderer uses an isolated offscreen Quickshell runtime and exports PNG, GIF, WebP and MP4 to `docs/brand/`. It also copies the static poster and MP4 into `website/public/brand/`. The README uses GIF; these pages use muted, autoplaying MP4 on an infinite loop, without player controls, and a static image for reduced motion. Asset provenance and font licensing remain in the repository.
