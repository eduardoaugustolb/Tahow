## Arquitetura

| Camada | Responsabilidade |
| --- | --- |
| Config | Escrita única de preferências e resolução de escopo |
| Theme | Cores, fontes, material e movimento |
| Runtime | Serviços e superfícies compartilhadas |
| Host e adapters | Integração específica com o desktop |

A entrada `shell/shell.qml` permanece executável de forma independente. Imports do Ryoku pertencem aos adapters.

## Verificação

```sh
bun run check
bun test
bun tools/build-shaders.ts
bun tools/sync-i18n.ts
```

Depois de alterar shaders, inclua as fontes e os artefatos .qsb gerados. Strings do shell devem existir em en-US e pt-BR.

## Esta documentação

As páginas estão em `website/src/pages/{idioma}/*.mdx`. O layout está em `website/src/layouts/Docs.astro`. Os tokens CSS reproduzem Theme.qml e SettingsWindow.qml.

```sh
bun run docs:install
bun run docs:dev
bun run docs:build
```

O workflow de GitHub Pages compila o site estático com Bun. O domínio de produção é tahow.eduardoaugusto.work.

## Banner animado da marca

O banner aprovado combina o fundo glass-orbit gerado anteriormente, a logo aprovada e a fonte Sacramento incluída no projeto. Ele usa os shaders de fluxo e refração do texto da tela de recarregamento, além da deformação local da logo. Os contornos visíveis alinham logo e assinatura como um conjunto centralizado.

```sh
bun tools/build-shaders.ts
bun tools/animate-banner.ts
```

O renderizador usa uma instância isolada e offscreen do Quickshell e exporta PNG, GIF, WebP e MP4 para `docs/brand/`. Também copia o pôster estático e o MP4 para `website/public/brand/`. O README usa GIF; estas páginas usam MP4 mudo, com reprodução automática e loop infinito, sem controles de player, e uma imagem estática para movimento reduzido. A proveniência dos assets e a licença da fonte permanecem no repositório.
