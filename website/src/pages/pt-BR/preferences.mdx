## Onde ficam os ajustes

O arquivo canônico é `~/.config/tahow-shell/settings.json`, respeitando XDG_CONFIG_HOME. Enquanto ele não existe, o caminho legado `~/.config/tahoe-shell/settings.json` é lido como fallback; a primeira gravação usa o caminho canônico.

A inicialização lê o arquivo canônico antes de considerar a migração única do legado. As alterações são gravadas atomicamente antes de retornar, sem um salvamento pendente que possa se perder ao reiniciar a shell. Um arquivo existente ilegível ou inválido é preservado; erros de persistência são registrados nos logs.

## Geral e overrides

Os campos da raiz são gerais. Ajustes específicos ficam em `overrides.island`, `overrides.palette` e `overrides.lockscreen`.

```json
{
  "appearance": "dark",
  "accentSource": "wallpaper",
  "motion": "balanced",
  "overrides": {
    "island": { "glassOpacity": 0.55 },
    "palette": { "motion": "bouncy" },
    "lockscreen": { "use24h": true }
  }
}
```

## Voltar aos valores gerais

A ação Use General remove os overrides do componente. Na seção Glass, remove apenas os ajustes de vidro e preserva as outras preferências.

## Idioma e movimento

Escolha `en-US`, `pt-BR` ou seleção automática. Em modo hospedado, a seleção automática usa o padrão do Ryoku. Os perfis de movimento são gentle, balanced, bouncy e reduced.

A janela de preferências segue a aparência geral e o acento do desktop.
